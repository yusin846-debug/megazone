5별도 웹 화면 (직접 개발)

React 같은 도구로 화면을 처음부터 만듭니다. 원하는 대로 꾸밀 수 있지만 시간이 가장 많이 듭니다. 고객이 "세일즈포스도 메신저도 아닌 전용 화면"을 원할 때만 고릅니다.
