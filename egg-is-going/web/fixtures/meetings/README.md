# 가상 제작회의 5개 (평가 표본)

담당: 팀원 A. 실제 사람의 회의·이름을 쓰지 않는다. 모든 인물은 가상.

| 폴더 | 함정 |
|---|---|
| 01_opening | 기본 예시: 번복(야외→실내→스튜디오), 폐기(드론), 보류(게스트), 기한 없는 업무, 불확실 구간 |
| 02_reversal | 결정이 두 번 바뀜. 최종값과 각 변경 이유 |
| 03_noise | 잡담 속 결정 하나. "커피 사기"는 업무가 아님 |
| 04_hold | 보류 다수, 담당이 정해지지 않은 업무 |
| 05_overlap | 말 겹침 구간의 예산 숫자 → 확정 금지 |

## 파일
- `transcript.txt` — `[mm:ss] 이름: 발언` 한 줄에 한 발언. 화자를 모르면 `?`, 말이 겹치면 `(겹침)`
- `meeting.json` — 회의 이름·일시·참석자
- `gold.json` — 정답지 (메인 작가·PD 판정을 가정). `critical: true` 가 PRD의 "중대한 결정"

정답지를 고치거나 회의를 추가하면 `npm run agent:examples` 로 에이전트 테스트를 다시 만든다.
