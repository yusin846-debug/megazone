# AI 챗봇 제품 요구사항

v0.2 | 2026-10-22 | 검토용 초안 · 챗봇 추가안 (기준: 03_PRD v0.1)

본 문서는 방송작가 인터뷰를 가상 제작사 에그이즈고잉에 적용한 설계 초안이다. 실제 에그이즈커밍의 조직 운영이나 AIR Studio의 확정 API를 설명하지 않는다.

## 목표와 범위

| 항목 | 정의 |
|---|---|
| 목표 | 서로 다른 날짜에 열린 회의에서 나온 내용을 질문 한 번으로 종합해 확인한다 |
| 주 사용자 | 회의록 작성자, 검토·결재자, 프로그램 관리자 |
| 검색 범위 | **현재 선택한 프로그램에 올라온 회의 원문 전체** (승인 여부 무관) |
| 제외 | 다른 프로그램 회의 (예: "달걀 한 판 여행기"에서 "오늘 뭐하고 놀지" 회의는 검색 불가) |

### 범위 제외

프로그램 간 검색, 챗봇을 통한 원문·결정·회의록 수정, 답변을 결정이나 업무로 자동 등록, 대화 내용 서버 저장, 녹음 파일이 없는 회의의 실제 음성 재생.

## 사용자와 권한

| 역할 | 챗봇 사용 | 근거 |
|---|---|---|
| 작성자 | 가능 | 원문 열람 권한 보유 |
| 검토자 | 가능 | 허용 프로그램만 |
| 결재자 | 가능 | 허용 프로그램만 |
| 프로그램 관리자 | 가능 | 허용 프로그램만 |
| 운영자 (운영자 역할만 있는 경우) | **불가** | 기준 PRD "녹음·문서 내용 접근은 별도 허용" |

권한은 화면이 아니라 **백엔드에서** 매 요청마다 확인한다 (FR-08).

## 기능 요구사항

| ID | 우선순위 | 기능 | 수용 기준 |
|---|---|---|---|
| FR-11 | P1 | 프로그램 회의 원문 질의 검색 | 현재 선택한 프로그램의 모든 회의(전사 전 녹취록 포함)에서 검색한다. 멤버십이 없는 프로그램·다른 프로그램 회의는 결과에 나오지 않는다. 결과가 없으면 답을 지어내지 않는다. |
| FR-12 | P1 | 표기 오류·비슷한 표현 검색 | 단어가 같지 않아도 ① 받아쓰기 오류로 보이는 표기(모음 한 개 차이 등) ② 뜻이 비슷한 말을 찾는다. 비슷한 뜻·비슷한 표기는 이름을 붙인 태그로 표시하고, 정확히 같은 말은 태그 없이 둔다. |
| FR-13 | P1 | 근거 표시·이동·듣기 | 결과마다 회의 이름·회의 날짜·회의 시작 시각·녹음 위치(mm:ss)·화자·발언을 표시한다. 녹음 위치에 마우스를 올리거나 키보드로 이동하면 발언의 실제 시각(회의 시작 + 녹음 위치, 초 단위)을 보여 준다. 휴대폰 등 마우스가 없는 화면에서는 표시하지 않는다. 누르면 해당 원문 위치로 이동하고, 해당 발언을 들을 수 있다. |
| FR-14 | P1 | 조회·사용량 기록 | FR-14a 조회 기록: 질문 1건당 AuditEvent 1행 (**적용됨**). 거부된 시도는 `chatbot.search_denied`. FR-14b 사용량 기록: Claude 모드 도입 시 적용. |

### FR-09와의 관계 [기준 문서와 차이]

기준 FR-09(승인본 검색)는 **승인된 회의록 문서**를 대상으로 하며 "승인 상태를 만족하는 문서만" 검색한다. FR-11은 **회의 원문(녹취록)**을 대상으로 하므로 별도 요구사항으로 둔다. 원문은 승인 전에도 작성자·검토자가 이미 열람할 수 있는 자료이므로 같은 열람 권한 안에서 검색을 허용한다. "프로그램 간 검색은 별도 승인"이라는 FR-09의 원칙은 FR-11에도 그대로 적용한다.

## 기록 방식 (FR-14)

| 구분 | 제안 | 남기는 것 | 남기지 않는 것 |
|---|---|---|---|
| FR-14a 조회 기록 (적용됨) | 기존 `AuditEvent`에 질문 1건당 1행 | 사용자, `chatbot.search` 또는 `chatbot.search_denied`, 대상 프로그램, 시각 | 질문 본문, 답변, 원문 |
| FR-14b 사용량 기록 (보류) | Claude 모드 도입 시 새 테이블 `ChatbotUsage` 추가 | 공급자, 모델, 프롬프트 버전, 입력·출력 토큰, 응답 시간, 결과 수 | 질문 본문, 답변, 원문 |

근거: 기준 PRD FR-08 "조회 기록", 비기능 "원문 최소 로그·모델 버전 기록·토큰 분리 측정", 기준 ERD AuditEvent "원문 본문 대신 최소 식별정보".

## 품질과 비기능 요구사항

| 영역 | 설계 기준과 검증 |
|---|---|
| 범위 보안 | 모든 검색 쿼리에 `programId` 조건. 다른 프로그램 지정 시도는 멤버십 검사로 무시 |
| 원문 로그 | 질문·답변·원문을 서버 로그와 기록 테이블에 남기지 않음 |
| 정확성 | 답변은 찾은 발언(Claude 모드는 그 발언이 나온 회의 원문 전체)만 근거. 결정이 바뀐 경우 최신 회의 기준을 먼저 말함 |
| 장애 | AI 호출 실패 시 규칙 기반 결과로 응답 (검색 중단 없음) |
| 성능 | 질문마다 프로그램 회의 원문을 읽어 검색. 회의 수가 많아지면 검색 인덱스 도입 검토 (AIR Data 후보) |
| 재현성 | 사전(`synonyms.ts`)·프롬프트는 코드로 버전 관리 (프롬프트 사본과 검토는 [프롬프트.md](프롬프트.md)). 모델·프롬프트 버전은 FR-14b로 기록 예정 |

## 수용 테스트

| ID | 질문 / 조건 | 기대 결과 |
|---|---|---|
| AT-01 | "일몰 얘기 나온 거 다 찾아줘" | 2회차 엔딩 회의(10/20)와 엔딩 재점검 회의(10/22) 둘 다 나옴 |
| AT-02 | 녹취록에 "일물"로 적힌 발언 | "비슷한 표기 ‘일물’≈‘일몰’"로 표시 |
| AT-03 | "드론 촬영 어떻게 됐어?" | "드런"으로 적힌 발언도 찾음 |
| AT-04 | "엔딩 장소 어디로 정했어?" | "마무리" 발언에 "비슷한 뜻" 표시 |
| AT-05 | "장소" | "장보기" 같은 무관한 단어는 나오지 않음 |
| AT-06 | 두 프로그램 소속 사용자가 "달걀 한 판 여행기" 선택 | "오늘 뭐하고 놀지" 회의가 나오지 않음 |
| AT-07 | 같은 사용자가 "오늘 뭐하고 놀지" 선택 | 그 프로그램 회의만 나옴 |
| AT-08 | 소속 없는 프로그램으로 쿠키 조작 | 무시되고 자기 프로그램만 검색 |
| AT-09 | 운영자 계정 | 403, 검색 불가 |
| AT-10 | 로그인 안 함 | 401, 채팅 버튼 숨김 |
| AT-11 | 결과의 시각 버튼 `01:45`에 마우스 올림 (오후 3:30 시작 회의) | "오후 3:31:45 발언 · 원문 보기" 툴팁 |
| AT-12 | 결과 발언의 화자 | 화자 옆에 직함과 팀 색 표시 (예: 박준호 · 메인 PD · PD팀 색) |

## 미결정 사항

- FR-14b 사용량 테이블 추가 시점 (팀과 schema 변경 합의 필요)
- 녹음 파일 저장 방식 확정 전까지 "듣기"는 브라우저 음성 읽기로 대체할지
- 비슷한 말 사전의 관리 주체 (프로그램 관리자 화면에서 편집할지)
