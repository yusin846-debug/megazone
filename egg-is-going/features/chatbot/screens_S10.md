## 채택 이유

기능의 목적이 "서로 다른 날짜 회의 내용을 한 번에 종합"이라서, 결과를 **회의 날짜순 타임라인**으로 묶어 결정이 언제 어떻게 바뀌었는지 바로 보이는 B를 골랐다.

## 구성

```
┌─────────────────────────────────────────────┐
│ 회의 원문 검색  [🔒 달걀 한 판 여행기만]   ↻  ✕ │ ← 머리: 실제 검색 범위
├─────────────────────────────────────────────┤
│                        일몰 얘기 다 찾아줘 │ ← 내 질문
│ ┌─────────────────────────────────────────┐ │
│ │ 회의 2개 · 발언 5곳                       │ │ ← 답변 상자 (크림 배경)
│ │ 가장 관련 깊은 발언은 …                   │ │
│ └─────────────────────────────────────────┘ │
│ ○ 10월 20일 (화)  2회차 엔딩 구성 회의 · 오후 3:30 │ ← 회의 = 타임라인 점 하나
│ ┃ [00:08] 박준호 [메인 PD]          [▶ 듣기] │ ← 근거 바(노랑)는 가장 관련 깊은 1개만
│ ┃ 2회차 엔딩 장소 얘기해 봅시다 …            │
│ │ 이어서 · 오다은: 일몰 시간이 …            │ ← 다음 발언 (결론 맥락)
│ ● 10월 22일 (목)  엔딩 재점검 회의 · 가장 최근 │ ← 가장 최근 회의 = 블루베리 점
│   [00:15] 한지수 [메인 작가] [비슷한 표기 · 일물] │
├─────────────────────────────────────────────┤
│ [회의에서 나온 내용을 물어보세요   ] [➤ 질문하기] │ ← 노란 주요 버튼은 이것 하나
└─────────────────────────────────────────────┘
```

## 상태

| 상태 | 표시 |
|---|---|
| 처음 (대화 없음) | 평면 달걀 하나 + 기능 설명 두 줄 + 예시 질문 3개 |
| 찾는 중 | 흔들리는 달걀 + "회의 원문을 찾는 중…" |
| 결과 있음 | 답변 상자 + 날짜 타임라인 (최대 12발언) |
| 검색할 단어 없음 | 답변 상자에 "검색할 단어를 찾지 못했어요…" + 장소·게스트·예산 같은 단어로 다시 물어보라는 안내 |
| 결과 없음 | 답변 상자에 "이 프로그램 회의 원문에서 …와 관련된 내용을 찾지 못했어요" |
| AI 실패 | 규칙 기반 답변 + 답변 상자 아래 작은 회색 안내 |
| 운영자 | "운영자 권한으로는 회의 내용을 검색할 수 없어요", 입력 비활성 |
| 프로그램 전환 | 대화 초기화, 범위 칩의 프로그램 이름 변경 |

## 동작

- **시각 버튼 `00:08`:** 마우스를 올리거나 키보드로 이동하면 "오후 3:30:08 발언 · 원문 보기"처럼 발언의 실제 시각(회의 시작 + 녹음 위치)이 버튼 오른쪽에 뜬다. 화면 읽기 프로그램에는 같은 내용을 `aria-label`로 알린다. 휴대폰 등 마우스가 없는 화면에서는 뜨지 않는다 (결정 사항). 누르면 원문 위치로 이동 (`/meetings/{id}/workspace#seg_xx`, S4 작업실의 기존 앵커). 전사 전 회의는 작업실로만 이동한다.
- **듣기:** 녹음 파일이 있으면 해당 구간만 재생, 없으면 브라우저 음성으로 "화자. 발언"을 읽는다. 다시 누르면 멈춤.
- **닫기:** ✕ 버튼 또는 `Esc`. 닫으면 읽기도 멈춘다. 시트가 열려 있는 동안 여는 버튼은 숨긴다.

## 디자인 시스템 적용

| 규칙 (design-system.html) | 적용 |
|---|---|
| 노랑은 행동과 강조에만, primary 하나 | "질문하기" 버튼 + 가장 관련 깊은 발언의 근거 바만 노랑. 여는 버튼은 잉크색 |
| 근거가 먼저 보인다 | 모든 발언 앞에 블루베리 시각 버튼 (`eg-tsbtn`, JetBrains Mono) |
| 원문 행 | 작업실과 같은 `eg-line` / `is-evidence` |
| 화자 옆 팀 | `Team` 부품 (작가팀 노랑, PD팀 세이지). 화자를 모르면 `미확인` 값 자리 |
| 상태는 색과 글자로 | 일치 종류를 "비슷한 뜻 · 노을", "비슷한 표기 · 일물" 글자 태그로 |
| 달걀은 빈 화면·로딩에만, 한 화면 하나 | 처음 화면과 찾는 중에만 |
| 크림 위 흰 카드 | 시트는 흰색, 답변 상자만 크림 |
| 문구 원칙 | 해요체, 모르면 모른다고 ("찾지 못했어요") |

폭 640px 이하에서는 시트가 화면 전체 폭으로 열린다. 새 스타일은 `cb-` 접두사만 쓴다.
