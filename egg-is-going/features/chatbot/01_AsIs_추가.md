# 현재 업무의 회의 내용 찾기 병목

v0.1 | 2026-10-22 | 검토용 초안 · 챗봇 추가안 (기준: 01_Swimlane_AsIs v0.1)

본 문서는 방송작가 인터뷰를 가상 제작사 에그이즈고잉에 적용한 설계 초안이다. 실제 에그이즈커밍의 조직 운영이나 AIR Studio의 확정 API를 설명하지 않는다.

## 문제가 생기는 위치

기준 문서의 **A06 최종본 공유·다음 회의 활용** 단계는 병목을 "구버전 사용·맥락 단절"로 적었다. 제작회의는 회차마다, 날마다 따로 열리고, 같은 안건(엔딩 장소, 게스트 섭외, 예산)이 여러 회의에 걸쳐 바뀐다. 지난 결정을 확인하려면 회의록 파일을 하나씩 열어 찾아야 한다.

**A02 기록·AI 초안**의 병목 "화자 오인식"과 같은 원인으로 **단어 오인식**도 생긴다. 녹취록에 "일몰"이 "일물"로 적히면 단어 검색으로는 찾지 못한다.

## 단계별 업무와 병목 (추가분)

| ID | 담당과 작업 | 지금 방식 | 병목 |
|---|---|---|---|
| A06a | 작가·PD가 지난 회의 내용 확인 | 회의록 파일을 날짜별로 열어 직접 찾음 | 여러 날짜에 흩어진 내용을 종합하기 어렵다. 최신 결정이 무엇인지 헷갈린다 |
| A06b | 녹취록에서 특정 발언 찾기 | 단어 검색 (`Ctrl+F`) | 받아쓰기 오류·다른 표현("엔딩"↔"마무리")이면 못 찾는다 |
| A06c | 발언 맥락 확인 | 녹음 파일을 열어 시간 위치를 손으로 찾음 | 어느 회의 몇 분쯤인지 기억에 의존한다 |

## 챗봇이 줄이려는 것

| 병목 | 챗봇의 대응 | 연결 요구사항 |
|---|---|---|
| 회의별로 파일을 열어야 함 | 질문 한 번으로 프로그램 안의 회의 원문 전체를 찾는다 | FR-11 |
| 받아쓰기 오류·다른 표현 | 모음 오인식 비교, 제작 용어 사전, AI 검색어 확장 | FR-12 |
| 시간 위치를 손으로 찾음 | 회의 이름·날짜·시간을 표시하고 원문 위치로 바로 이동, 해당 발언 듣기 | FR-13 |

## 확인 질문

- 지난 회의 내용을 찾는 데 하루 몇 번, 몇 분이 드는가? (기준 시간 4.5시간에 포함되는지)
- 다른 프로그램 회의를 참고할 일이 있는가? (이번 추가안은 **불가**로 정함. 필요하면 FR-09처럼 별도 승인)
- 녹취록 받아쓰기 오류는 주로 어떤 단어에서 생기는가? (사전 보강용)
