# AI 챗봇 추가안

v0.2 | 2026-10-22 | 검토용 초안

기준 문서 01~05(v0.1, 2026-10-20)에 **AI 챗봇(지난 회의 원문 질의 검색)** 기능을 더하는 추가안이다. 기준 문서는 고치지 않고, 같은 번호 체계(A·T·FR·S)를 이어 쓴다. 기준 문서와 다르게 정한 부분은 각 문서에 **[기준 문서와 차이]**로 표시한다.

본 문서는 가상 제작사 에그이즈고잉 대상 교육 프로젝트의 설계 초안이며 실제 기업·인물, AIR Studio 확정 API와 무관하다.

## 한 줄 요약

선택한 **프로그램 안에서 올라온 회의 원문 전체**를 질문 하나로 찾고, 받아쓰기 오류·비슷한 표현까지 잡아 **회의 이름·날짜·시간과 원문 근거**로 보여 준다. 다른 프로그램 회의는 검색하지 않는다.

## 결정 기록

| 날짜 | 결정 | 결정자 |
|---|---|---|
| 2026-10-22 | 검색 범위는 승인 여부와 무관하게 "선택한 프로그램의 회의 원문 전체". 다른 프로그램은 검색 불가 (FR-09와 별도 요구사항 FR-11로 정의) | 사용자 |
| 2026-10-22 | 기존 코드는 최대한 건드리지 않는다. 새 파일 추가 + `layout.tsx` 2줄만 수정 | 사용자 |
| 2026-10-22 | 조회 기록(FR-14a)은 기존 AuditEvent로 즉시 적용. 사용량 기록(FR-14b)은 Claude 모드 도입 시 `ChatbotUsage` 테이블로 추가 | 사용자 |
| 2026-10-22 | 화면은 시안 B "날짜 흐름 시트"로 적용 (시안: [design/chatbot-mockups.html](design/chatbot-mockups.html)) | 사용자 |
| 2026-10-22 | 발언의 실제 시각은 시각 버튼에 마우스를 올리면 툴팁으로 표시. **휴대폰(마우스 없는 화면)에서는 표시하지 않아도 된다** | 사용자 |
| 2026-10-22 | AI(Claude) 연동은 **추후 사람이 검토한 뒤** 넣는다. 그전까지는 mock 모드(규칙 기반)로 동작 | 사용자 |
