MinuteMerge — 미팅 분석 → 양식 선택 → 머지필드 작성 → 자동 게시

회의 내용을 회사 표준 양식(회의록, 보고서)에 맞춰 채워 넣고, 필요한 곳에 올려 주는 에이전트 제품 작성: 2026-10-16 · 작성 관점: AI PoC 솔루션 엔지니어

1. 한 줄 요약

“회의는 사람이 하고, 회의록과 보고서는 회사 양식대로 에이전트가 채운다. 모든 칸에는 근거가 붙는다.”

녹취나 메모를 넣으면 에이전트가 ① 어떤 회의인지 판단하고 ② 맞는 양식을 고르거나 새로 제안하고 ③ 양식의 머지필드를 채우고 ④ 사람이 확인한 뒤 ⑤ 드라이브, 슬랙, 세일즈포스, 지라 같은 곳에 알맞게 올린다.

2. 왜 필요한가

기존 AI 회의 요약 도구의 한계

줌, 팀즈, 클로바노트 같은 도구도 회의를 요약해 준다. 하지만 기업 현장에서는 이런 불만이 남는다.

불만 설명
회사 양식이 아니다 요약은 자유 형식이다. 회사가 정한 회의록·보고서 양식에 다시 옮겨 적어야 한다
근거를 모른다 “결정사항: 예산 10% 증액”이 정말 회의에서 나온 말인지 확인하려면 녹취를 다시 들어야 한다
올리는 건 사람 몫 요약을 만든 뒤 드라이브 업로드, 슬랙 공유, CRM 입력, 할 일 등록을 사람이 따로 한다
한 회의, 여러 문서 같은 회의로 내부 회의록, 고객 발송용 요약, 주간 보고서 한 줄을 각각 만들어야 한다

세일즈포스 관리자 관점의 비유

세일즈포스에는 이미 머지필드로 문서를 만드는 도구(이메일 템플릿, 문서 생성 도구 등)가 있다. 다만 이 도구들은 이미 정리된 CRM 데이터로 칸을 채운다.

MinuteMerge는 정리되지 않은 대화에서 칸을 채운다. 이 차이가 제품의 핵심이다.

3. 누가 쓰나

페르소나 지금의 고충 MinuteMerge가 주는 것
회의 주관자·PM 회의 끝나고 회의록 정리에 30분~1시간 확인만 하면 되는 회의록 초안
영업 담당자 고객 미팅 후 CRM 입력, 내부 보고, 고객 감사 메일을 따로 씀 한 번에 세 가지 문서 + 세일즈포스 활동 기록
팀장 팀원들의 회의 결과를 모아 주간 보고서를 씀 한 주 회의록에서 주간 보고서 칸을 자동으로 채움
컴플라이언스·감사 (금융·공공) 정해진 양식의 회의록 보관 의무, 누락 위험 필수 칸 누락 검사, 근거 기록, 보관 이력

② 회의 유형 판단 (예시)

회의 유형 신호
고객 미팅 외부 참석자, 제안·가격·일정 이야기
주간 팀 회의 내부 참석자, 진행 상황 공유, 이슈
프로젝트 킥오프 목표, 역할 분담, 일정 수립
장애 회고 장애 시각, 원인, 재발 방지
1:1 면담 참석자 2명, 피드백·목표

③ 양식 결정: 고르거나, 만들거나

  • 고르기: 회사가 등록한 양식 중 회의 유형에 맞는 것을 고른다. 여러 개가 맞으면 후보를 보여 준다.
  • 만들기: 맞는 양식이 없으면 회의 내용을 보고 새 양식의 칸 구성을 제안한다 (예: “장애 회고 양식이 없습니다. 장애 개요 / 타임라인 / 원인 / 영향 / 재발 방지 / 담당자 칸으로 만들까요?”). 사람이 승인하면 라이브러리에 저장되어 다음부터 쓴다.

④ 머지필드 채우기: 양식은 ’칸 정의서’를 가진다

양식마다 칸의 이름, 형식, 필수 여부, 채우는 방법을 정의한다.

template: 고객 미팅 회의록
fields:
  - name: 고객사
    type: text
    required: true
  - name: 참석자
    type: person_list        # 사내 인원은 조직도와 대조
    required: true
  - name: 미팅_일시
    type: datetime
    required: true
  - name: 고객_요구사항
    type: bullet_list
    hint: "고객이 원한다고 말한 것만. 우리 측 제안은 제외"
  - name: 결정사항
    type: bullet_list
    hint: "양측이 합의했다고 명확히 말한 것만"
  - name: 액션아이템
    type: table              # 할 일 | 담당자 | 기한
    required: true
  - name: 가격_논의
    type: text
    sensitivity: internal    # 고객 발송용 문서에는 넣지 않음
destinations:
  - google_drive: /영업/고객미팅/{고객사}/
  - salesforce: 활동(Task) 기록 + 다음 단계 필드
  - slack: "#영업1팀" 요약 3줄
  - jira: 액션아이템을 티켓으로 (선택)

채우는 원칙 - 모든 칸에 근거 문장과 녹취 시각을 붙인다 (“결정사항 1 ← 23:41 ‘그럼 3년 계약으로 진행하시죠’”) - 근거가 없으면 지어내지 않고 “확인 필요”로 비워 둔다 - 형식을 검사한다: 날짜가 날짜인지, 담당자가 실제 직원인지, 필수 칸이 빠졌는지 - sensitivity 표시가 있는 칸은 외부 발송용 문서에서 자동으로 빠진다

⑤ 사람의 확인

  • 칸마다 값, 근거, 확신도를 나란히 보여 준다
  • 확신도가 낮거나 “확인 필요”인 칸을 맨 위로 올린다
  • 사람이 고친 내용은 기록해 두고, 같은 양식의 채우기 규칙(hint) 개선에 쓴다

⑥ 게시: 한 회의에서 여러 결과물

결과물 목적지
내부 회의록 (전체) 구글 드라이브·셰어포인트·컨플루언스
요약 3줄 슬랙·팀즈 채널
고객 발송용 요약 (민감 칸 제외) 메일 초안
활동 기록, 다음 단계 세일즈포스
액션아이템 지라·아사나 티켓, 캘린더
주간 보고서 한 줄 주간 보고서 양식의 해당 칸에 누적

5. 화면 구성

# 화면 핵심
1 업로드 녹취 파일·텍스트·회의 도구 녹취록 넣기, 참석자 확인
2 양식 선택 추천 양식 1순위 + 후보, “새 양식 만들기” 제안 카드
3 검토 화면 (핵심) 왼쪽: 양식 미리보기 / 오른쪽: 칸별 값·근거·확신도, “확인 필요” 강조
4 게시 목적지별 결과물 미리보기, 체크하고 한 번에 올리기
5 양식 라이브러리 (관리자) 양식 등록·수정, 칸 정의서 편집, 양식별 사용량과 수정률

AIR Studio가 필요한 이유: 회의 녹취는 회사에서 가장 민감한 데이터 중 하나다. 누가 어떤 회의록을 볼 수 있는지, 어떤 칸이 밖으로 나가면 안 되는지, 누가 무엇을 올렸는지를 한곳에서 통제해야 한다. AIR Studio의 Governance 모듈이 이 부분을 맡는다.

8. 데모 시나리오 (4분)

  1. (입력) 15분짜리 가상 고객 미팅 녹취록을 올린다.
  2. (양식 선택) “고객 미팅입니다. ‘고객 미팅 회의록’ 양식을 추천합니다.”
  3. (검토) 칸이 채워진 회의록이 나온다. “결정사항”을 클릭하면 근거 문장과 녹취 시각이 나온다. “기한” 칸 하나가 “확인 필요”로 강조되어 있다 → 사람이 날짜를 입력한다.
  4. (게시) 체크박스 4개(드라이브 회의록 / 슬랙 요약 / 세일즈포스 활동 / 고객 메일 초안)를 선택 → 한 번에 게시.
  5. (확인) 고객 메일 초안에는 내부용 “가격 논의” 칸이 빠져 있다.
  6. (새 양식) 이번엔 장애 회고 녹취를 올린다 → “맞는 양식이 없습니다. 이렇게 만들까요?” → 승인 → 라이브러리에 저장.
  7. (마무리) “회의록 1시간이 확인 5분으로. 회사 양식 그대로, 모든 칸에 근거를 붙여서.”

9. PoC 패키지 (4주)

주차 할 일
1주 고객사의 기존 회의록·보고서 양식 수집, 칸 정의서 작성, 성공 기준 합의
2주 양식 2~3종으로 추출·검토 화면 구축, 과거 회의록으로 정확도 측정
3주 게시 목적지 2곳 연결 (예: 드라이브 + 슬랙 또는 세일즈포스), 민감 칸 규칙
4주 실사용자 10명 2주간 사용, 측정, 결과 보고

성공 기준

지표 측정 방법
회의록 작성 시간 도입 전후 비교
칸 정확도 사람이 수정 없이 승인한 칸의 비율
지어낸 내용 근거 없는 값이 들어간 횟수 (목표: 0)
필수 칸 누락 게시 전 검사로 걸러진 비율
사용률 회의 후 MinuteMerge로 회의록을 만든 비율

11. 경쟁과 차별점

회의 도구의 AI 요약 (줌·팀즈 등) MinuteMerge
결과물 형식 도구가 정한 자유 형식 회사 표준 양식 + 머지필드
근거 일부 제공 모든 칸에 근거 문장·시각
빈칸 처리 그럴듯하게 채울 위험 “확인 필요”로 남김
게시 해당 도구 안에서 공유 드라이브·슬랙·CRM·지라 등 여러 곳에 자동 게시
양식 고정 회의를 보고 새 양식 제안, 라이브러리로 축적
통제 도구별 설정 AIR Studio에서 전사 권한·민감 정보·감사 로그 관리

정직하게 말할 점: 회의 도구들의 AI 기능도 빠르게 좋아지고 있다. 차별점은 요약 품질이 아니라 “회사 양식, 근거, 여러 시스템 게시, 전사 통제”에 둬야 한다.

12. 위험과 대응

위험 대응
한국어 음성 인식 오류, 화자 구분 실수 녹취록 업로드도 지원, 참석자를 먼저 확인받기, 근거 시각으로 재확인 쉽게
AI가 내용을 지어냄 근거 없는 값 금지, “확인 필요” 처리, 사람 확인 없이는 게시 불가
녹음 동의·개인정보 녹음 전 참석자 동의 안내, 보관 기간 설정, 민감 칸 규칙
외부로 나가는 문서의 실수 고객 발송용은 민감 칸 자동 제외 + 반드시 사람이 발송
한글(HWP) 양식 요구 (공공·일부 기업) 2단계 과제로 검토 (한글 문서의 XML 형식 활용 가능성 확인 필요)

13. 다른 기획과의 관계

MinuteMerge는 여러 제품에 들어가는 공통 엔진이 될 수 있다.

제품 MinuteMerge가 쓰이는 곳
AIR Deal Desk (최종 포트폴리오) “CRM 자동 입력” 에이전트 = 고객 미팅 양식 + 세일즈포스 게시
Lookie Zone (팀플) 운영진 회의록, 교육 운영 주간 보고서
일반 기업 주간 회의, 장애 회고, 1:1 면담 기록
